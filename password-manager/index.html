Trình quản lý mật khẩu

Mã hóa dữ liệu chuẩn AES-GCM 256-bit.

Ứng dụng hỗ trợ lưu trữ cục bộ các tài khoản của bạn, vận hành an toàn tuyệt đối 100% không gửi dữ liệu qua mạng internet.

  • Mã hóa Web Crypto API (AES-GCM).
  • Dẫn xuất khóa PBKDF2 (210.000 vòng lặp).
  • Hoạt động ngoại tuyến 100%.
  • Cảnh báo: Quên mật khẩu chính sẽ vĩnh viễn mất dữ liệu.
